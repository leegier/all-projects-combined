# Affiliate Programs — Quick Reference

## Best Programs for MAX's Use Case

### Amazon Associates
- **Commission:** 1–10% (varies by category)
- **Cookie:** 24 hours
- **Payout:** $10 minimum, monthly
- **Best for:** Books, hardware, game gear
- **Sign up:** https://affiliate-program.amazon.com
- **Tag format:** Add `?tag=YOUR-TAG` to any amazon.com URL

### Gumroad Affiliate Program
- **Commission:** Up to 50% (set by creator)
- **Cookie:** 30 days
- **Best for:** Digital products, templates, ebooks
- **How:** Any Gumroad seller can enable affiliates in their settings
- **Link format:** `https://gum.co/PRODUCT?wanted=true&ref=YOUR_ID`

### ShareASale
- **Commission:** Varies (5–50%+)
- **Payout:** $50 minimum
- **Best for:** Software, SaaS, ecommerce tools
- **Sign up:** https://www.shareasale.com

### Impact.com (formerly Impact Radius)
- **Commission:** Varies
- **Best for:** Major software brands (Canva, Semrush, etc.)

### itch.io Referral
- **Commission:** None built-in, but tracking links show referral traffic
- **How:** Share `https://itch.io/game/clawed?ref=YOUR_HANDLE`

## Commission Rate Benchmarks

| Category | Typical Rate |
|----------|-------------|
| Digital products / ebooks | 30–50% |
| SaaS software | 20–30% |
| Physical products | 3–8% |
| Amazon books | 4.5% |
| Games | 5–15% |
| Hosting/domains | $50–$150 flat |
