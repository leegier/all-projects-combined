# What Makes Top Product Hunt Listings Succeed

## Tagline Patterns (from top 100 launches)

Analyzed from top 100 launches by upvote count:

| Pattern | Example |
|---------|---------|
| Problem → Solution | "Stop losing leads. Close more deals." |
| Audience-specific | "The CRM built for indie hackers" |
| Bold claim + qualifier | "Ship 10x faster — no code required" |
| Verb-led action | "Turn any website into an API" |
| Contrast | "Design like a pro. Code like never." |

**Avoid:** "Revolutionary", "game-changing", "AI-powered X for the modern era"

## Gallery Best Practices

- Image 1: Hero shot — product UI or game screenshot. Dark backgrounds pop.
- Image 2: Feature highlight or use case
- Image 3: Social proof (stats, reviews) or "how it works"
- GIFs outperform static images by ~25%
- No walls of text in images — 6 words max per slide

## Maker Comment Formula

```
[Hook: why I built this — personal story, 2 sentences]

[What it does — plain English, no jargon, 2-3 sentences]

[What I learned or what makes it different, 2 sentences]

[Ask: "I'd love feedback on X" or "AMA about Y"]

[CTA: Try it here: [URL] — it's [free/free to start/$X]]
```

## Categories That Convert

High-engagement PH categories for indie devs/solopreneurs:
- `Developer Tools` — large audience, technical users who upvote prolifically
- `Productivity` — broad audience
- `Games` — smaller but passionate community
- `Open Source` — dedicated upvoter base

## Realistic Expectations

| Upvotes | Outcome |
|---------|---------|
| 0-50 | Launched, minimal traction |
| 50-200 | "Product of the Day" in niche category |
| 200-500 | Front page visibility, 100-500 signups |
| 500+ | Top 5 of day, major traffic spike |

Most indie launches: 50-150 upvotes without an existing audience.
With 500+ email subscribers or Twitter followers: 200-500 realistic.
