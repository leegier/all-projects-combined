# Gumroad Listing Best Practices

## Pricing

- **Pay-what-you-want ($0+)** with a suggested price converts better than free
- Sweet spots: $5, $9, $15, $29 for digital tools/templates
- Early access: set low ($2.99–$4.99), raise price after reviews accumulate
- Discount codes for launch: 40–50% off for first 48h drives initial sales velocity

## Product Description

- Lead with the outcome: "Ship faster / Save 10 hours / Build X without Y"
- Include a short demo GIF or screenshot above the fold
- Bullet point features — don't wall-of-text
- End with a simple guarantee ("If it doesn't work as described, full refund")

## Tags & Discovery

Gumroad has weak SEO — drive traffic externally:
- Reddit (r/gamedev, r/Unity3D, r/SideProject)
- Product Hunt launch
- Twitter/X devlog posts
- Indie Hackers

## File Formats That Sell Well

- `.zip` with a clear folder structure + README
- PDF guides (Notion → Export to PDF)
- Unity `.unitypackage` files
- Google Sheets templates (export as .xlsx)

## Buyer Update Strategy

Send 1 email per major version:
- What changed (3 bullet points)
- Download link reminder
- Optional: teaser for next version
