I got tired of losing good prompts in random Notion pages and text files. So I built a single-file browser tool to manage them.

**AI Prompt Vault** — it's one `.html` file. Open it in any browser. Works offline. No login, no server, nothing to install.

## What it does

- 50 pre-loaded prompts across 7 categories (Writing, Coding, Marketing, SEO, Sales, Image Gen, Business)
- Star ratings + favorites so you surface what actually works
- Copy counter so you see which prompts you use most
- Full-text search across prompt title, body, and tags
- Import/export your whole library as JSON
- Keyboard shortcuts: `Ctrl+K` to search, `Ctrl+N` for new prompt

## Why a single HTML file?

No dependencies means no npm install, no Python env, no Docker. Your prompts live in your browser's localStorage — private, instant, always available.

## The 50 prompts are actually good

Not filler. Specific, production-tested prompts with `{{fill-in-the-blank}}` placeholders:

- Full 5-part cold email sequences
- Code review expert that explains *why* something is wrong
- YouTube script writer with hooks baked in
- 30-day content calendar generator
- SPIN sales discovery call script
- Midjourney cinematic portrait prompts
