# MAX Memory Graph

This Obsidian vault is linked to the OpenClaw workspace.

## How to Open the Real Vault

When you open Obsidian, choose **"Open folder as vault"** and select:
```
Z:\openclaw\workspace
```

This gives you the full memory graph with all files linked.

## Key Files in the Graph
- [[MEMORY.md]] — Long-term memory (most important)
- [[SOUL.md]] — Identity and personality
- [[MISSION.md]] — Revenue strategy
- [[HEARTBEAT.md]] — Daily task schedule
- [[memory/]] — Daily logs folder

## Graph View Tips
- Press Ctrl+G to open graph view
- Color coding: daily memory = blue, MEMORY.md = red, revenue = green
- Use the search filter to explore by topic
