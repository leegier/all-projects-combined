# Outreach Email Templates

## Template Format

First line of template file = subject line (prefixed `SUBJECT:`)
Remaining lines = body
Placeholders: `{name}`, `{company}`, `{custom1}`, etc.

---

## Cold Outreach — Freelance Services

```
SUBJECT: Quick question about {company}'s dev needs
Hi {name},

I help companies like {company} ship features faster with Unity/C# and automation scripting.

Curious if you have any backlog work that's been sitting — I can usually turn around small-to-mid projects in 1–2 weeks.

Worth a quick call? Happy to share examples.

— Lee
```

---

## Follow-Up (3 days after no reply)

```
SUBJECT: Re: Quick question about {company}'s dev needs
Hey {name},

Just bumping this up in case it got buried. No pressure if the timing isn't right.

If you do have something coming up, I'm available starting next week.

— Lee
```

---

## Proposal Sent — Follow-Up

```
SUBJECT: Following up on my proposal
Hi {name},

Wanted to make sure you received my proposal for {custom1}.

Happy to jump on a quick call to walk through it or adjust scope if needed.

— Lee
```
