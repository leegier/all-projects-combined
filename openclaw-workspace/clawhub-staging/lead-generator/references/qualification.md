# Lead Qualification Checklist

Before spending time on a proposal, confirm:

## Green Lights (pursue)
- [ ] Budget posted and >= $100 for small tasks, >= $300 for multi-day work
- [ ] Posted within 72 hours (older posts are often filled)
- [ ] Scope is clear — you can visualize delivering it
- [ ] Client has history (reviews, completed projects on platform)
- [ ] Requires your actual skills (Unity, C#, Python, automation)

## Yellow Flags (proceed carefully)
- [ ] Budget listed as "negotiable" or not listed — ask before investing time
- [ ] Vague scope ("help with my game") — ask clarifying questions in proposal
- [ ] New client account, no reviews — possible but ask for milestone payment
- [ ] Very long description with many requirements — risk of scope creep

## Red Flags (skip)
- [ ] "Unpaid / revenue share / equity only"
- [ ] Budget clearly too low for scope (e.g., $10 for "a full game")
- [ ] No response to previous applicants in comments
- [ ] Posting history shows disputes or bad reviews
- [ ] Requires NDA before sharing scope details (unusual for small jobs)

## Fast Filter Rule

If you can't answer "What exactly will I deliver, in how many hours, for how much?" in 30 seconds — it's a yellow flag or skip.

## Score Threshold

| Score | Action |
|-------|--------|
| 70–100 | Write proposal now |
| 40–69 | Review manually, write if good fit |
| 0–39 | Skip unless nothing else available |
