# Lead Search Patterns by Source

## Upwork RSS Keywords

Best performing queries for game dev / automation work:

```
unity game developer
c# unity
unreal engine developer
game automation
unity 3d
python automation script
browser automation
web scraper python
```

URL format: `https://www.upwork.com/ab/feed/jobs/rss?q=QUERY&sort=recency`

## Reddit /r/forhire

Filter for: posts starting with `[HIRING]`

High-value subreddits:
- `/r/forhire` — general, mix of budgets
- `/r/gamedev` — specific to game work, usually has budget listed
- `/r/Unity3D` — Unity-specific, developers posting "need help"
- `/r/slavelabour` — micro gigs ($5–50, fast turnaround, volume play)

RSS: `https://www.reddit.com/r/forhire/new.rss`

## Hacker News "Who Is Hiring"

Posted monthly (first weekday of month). Search for roles via:
`https://hn.algolia.com/api/v1/search_by_date?query=unity+game&tags=comment&numericFilters=...`

Best roles: startups, remote, comp listed in comments.

## Algora Bounties

`https://algora.io/bounties` — JS-rendered, needs browser to scrape live.
Filter: open + $100+ reward. Unity/C# bounties rare but high quality.

## GitHub Issues with Bounty Labels

Search: `https://github.com/search?q=label%3Abounty+is%3Aopen&type=issues`
Or check Bountysource: `https://www.bountysource.com`
