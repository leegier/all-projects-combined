## 🚀 Quick Start Guide

### Setting Up Upwork
1. Go to upwork.com → Profile → Edit
2. Copy the bio from `upwork-profile-bio.md` into your Overview section
3. Set your hourly rate: $65–$85/hr (adjust based on confidence)
4. Upload screenshots of `landing-page-sample.html` as portfolio items
5. Add skills: Python, Web Scraping, Automation, AI, HTML/CSS, React

### Setting Up Fiverr
1. Go to fiverr.com → Selling → Gigs → Create New Gig
2. Copy title and description from the relevant gig file
3. Set packages exactly as shown in the pricing tables
4. Upload portfolio screenshots as gig images
5. Enable "Quick Response" badge by responding to messages within 1 hour

### Sending Proposals (Upwork)
1. Search for jobs in: "Python", "web scraper", "automation", "landing page", "AI"
2. Filter by: Posted last 24h, Budget $200+, Payment Verified
3. Pick the matching cover letter from the gig file
4. Customize the first line to reference something specific in their job post
5. Always end with a specific question to drive a response
