# Environment Variables Required

Set these in Windows System Environment Variables:
Win+R → sysdm.cpl → Advanced → Environment Variables → User Variables → New

| Variable | Description | Where to get it |
|----------|-------------|-----------------|
| ANTHROPIC_API_KEY | Claude API — powers all AI scripts | console.anthropic.com |
| OPENAI_API_KEY | GPT-5.4 for Arianna coding agent | platform.openai.com |
| DISCORD_MISSION_CONTROL | Channel ID for #mission-control | Discord: right-click channel → Copy ID |
| DISCORD_STOCK_RESEARCH | Channel ID for #stock-research | Discord: right-click channel → Copy ID |
| DISCORD_TREND_SCOUT | Channel ID for #trend-scout | Discord: right-click channel → Copy ID |
| DISCORD_DAILY_BRIEF | Channel ID for #daily-brief | Discord: right-click channel → Copy ID |
| DISCORD_CONTENT_PIPELINE | Channel ID for #content-pipeline | Discord: right-click channel → Copy ID |
| X_BEARER_TOKEN | X/Twitter API bearer token | developer.twitter.com |
| REDDIT_CLIENT_ID | Reddit API client ID | reddit.com/prefs/apps |
| REDDIT_CLIENT_SECRET | Reddit API secret | reddit.com/prefs/apps |
| YOUTUBE_API_KEY | YouTube Data API v3 | console.cloud.google.com |

## To enable Developer Mode in Discord (to see channel IDs):
Settings → Advanced → Developer Mode ON
Then right-click any channel → Copy Channel ID
