🟢 DEPLOY IN 5 MINUTES (GITHUB PAGES - RECOMMENDED)
═══════════════════════════════════════════════════════════════════════════════

1. Go to: https://github.com
   → Create account (free) if you don't have one

2. Click: "+" → "New repository"

3. Name it: "nyghtshade" (or any name)
   → Make it PUBLIC

4. Click: "Create repository"

5. In the repo, click: "uploading an existing file"
   → Drag and drop: index.html

6. Click: "Commit changes"

7. Go to: Settings → Pages

8. Select:
   - Source: "Deploy from a branch"
   - Branch: "main" → "/" (root)
   - Click: Save

9. Wait 2-3 minutes

10. Your URL: https://YOUR-USERNAME.github.io/nyghtshade/

🆘 COMMON ISSUES
═══════════════════════════════════════════════════════════════════════════════

"Page not showing"
→ Wait 2-3 minutes after uploading
→ Clear browser cache (Ctrl+Shift+Delete)
→ Ensure file is named "index.html" (not "nyghtshade.html")

"Styles look broken"
→ Check that complete index.html file was uploaded
→ Open browser console (F12) to see errors

"404 Error"
→ File must be named "index.html"
→ Check your deployment settings
