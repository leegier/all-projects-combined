## 🎯 Quick Customization

### Change Colors
Edit the CSS variables (line 20 in index.html):
```css
--neon-cyan: #00fff9;      ← Change these
--neon-purple: #b829f6;    ← to your colors
--neon-pink: #ff0099;      ← for branding
```

### Change Text
Use Find & Replace:
- `NYGHTSHADE` → Your product name
- `$5`, `$20` → Your pricing
- Feature descriptions → Your features
- Any text → Your content

- Hero tagline
