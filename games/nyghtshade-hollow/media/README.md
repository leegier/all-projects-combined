# Media

| File | What |
|---|---|
| `nyghtshade-hollow-playtest.mp4` | Automated playtest recording, 1280×720 · 30 fps · H.264 + AAC, with chapter markers (see below) |
| `nyghtshade-hollow-playtest-lite.mp4` | Same video, 854×480, small enough to preview anywhere |
| `stills/*.jpg` | 1280×720 stills picked from the capture (intro, count, chow, Cutter, Records, chapel, tunnel, clearing, ending…) |
| `contact-sheet.jpg` | One frame every ~8 s of the golden path, for a quick visual review |

The video is **not** a screen recording of someone playing: the bot drives the real game through its input layer, a
deterministic capture pipeline renders every frame, and the soundtrack is rendered offline from the same simulation.
How it is made, what the overlays mean and how to reproduce it: [`../docs/VIDEO.md`](../docs/VIDEO.md).
